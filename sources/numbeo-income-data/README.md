# Numbeo Income Data

自动抓取 Numbeo 各国平均月净工资 (Average Monthly Net Salary After Tax) 数据。

## 数据

- **来源**: [Numbeo](https://www.numbeo.com/cost-of-living/country_price_rankings?itemId=105)
- **字段**: rank / country / monthly_net_salary_usd
- **更新**: 每天 UTC 2:00（北京时间 10:00）
- **文件**: `data/numbeo-income.json`
